# Kody the Carpenter — Page Map

**22 colouring pages.** Cover is a separate coloured file, not designed yet.

Print file is **A5, 48 pages, single-sided.** Each colouring page faces a blank reverse so markers do not bleed.

One page per build. No Plan / Build / Done.

---

## Cover (not a colouring page)

**Title:** Kody the Carpenter
**Subtitle:** A Colouring Book

Kody full-body, hard hat, tool belt, working pose (not a wave). Colour the hat yellow. No Koda Built logo.

## Opening (pages 1 to 8)

Already drawn in `pages/opening/`. Workday, not a pose reel. Different body positions each page.

### Page 1 — Meet Kody
**Visual:** Kody walks up the driveway toward his open garage, a board under his arm.
**Caption:** "This is Kody. Kody loves to build!"

### Page 2 — Workshop
**Visual:** Inside, he leans over a plan on the workbench.
**Caption:** "This is where Kody builds."

### Page 3 — Hammer
**Visual:** Hammering a nail into a board on the bench.
**Caption:** "Kody's hammer. Bang, bang, bang!"

### Page 4 — Saw
**Visual:** A long timber sits on TWO sawhorses. Handsaw blade is in the wood, mid-cut.
**Caption:** "Kody's saw cuts the wood."

### Page 5 — Tape measure
**Visual:** Kneeling, stretching the tape along the board. Numbers 1, 2, 3.
**Caption:** "Kody always measures first."

### Page 6 — Level
**Visual:** Spirit level on the board. Checks the bubble. Not a belt close-up.
**Caption:** "Is it straight? Kody checks."

### Page 7 — Safety
**Visual:** Pulling on a glove. Glasses and ear muffs already on.
**Caption:** "Glasses, ears, gloves. Safety first!"

### Page 8 — Ready
**Visual:** Carrying a stack of cut boards. Both hands on the wood.
**Caption:** "Kody is ready. Let's build something!"
